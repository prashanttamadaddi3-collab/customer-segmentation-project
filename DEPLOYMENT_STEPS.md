# Deployment checklist

1. Create a GitHub repository named `customer-segmentation-project` under the intended GitHub owner.
2. Upload the *contents* of this folder (not only the ZIP), including `app.py`, `analysis.py`, `requirements.txt`, `README.md`, `PROJECT_REPORT.md` and `data/customer_data.csv`.
3. Open Streamlit Community Cloud and sign in with GitHub.
4. Choose **Create app**, select the repository and branch, and set main file path to `app.py`.
5. Deploy and wait for the build to finish.
6. Open the live URL and verify the KPI cards, charts, tabs, customer filters and CSV downloads.
7. Submit the repository URL (and live URL too if the portal permits it).

Do not claim the site is live until steps 5–6 succeed. Never add passwords, access tokens or secrets to the repository.
